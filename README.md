# Perro Sénior

Prototipo estático en español para una web de comparativas y guías de bienestar para perros adultos.

El comparador incluye una primera selección de camas, escaleras, rampas, arneses, carrito, suplemento articular y productos de higiene. Los enlaces de Amazon son búsquedas ordinarias, no enlaces de afiliado ni garantía de disponibilidad. El comparador no muestra precios copiados: el usuario consulta el importe vigente en Amazon.

## Ejecutar

Abre `index.html` en el navegador. No necesita dependencias ni proceso de compilación.

## Antes de publicar ofertas reales

- Sustituir los productos de ejemplo por artículos revisados y enlaces de afiliado autorizados.
- Confirmar acceso y condiciones vigentes de Amazon Afiliados / Creators API para los datos que se quieran mostrar.
- No almacenar ni presentar histórico propio de precios de Amazon sin autorización expresa. El prototipo plantea enlazar a un proveedor externo compatible y mostrar fecha y contexto cuando proceda.
- Añadir avisos legales, privacidad y cookies adecuados antes de recoger datos o usar analítica.

El nombre **Perro Sénior** y el logotipo SVG son una propuesta inicial pendiente de comprobar disponibilidad de marca y dominio.
